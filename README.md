# BREAK TIMER v1.4

Minimalistyczna aplikacja internetowa (PWA) stworzona z myślą o zdrowiu i profilaktyce siedzącego trybu życia. Jej głównym celem nie jest tradycyjna „produktywność”, lecz regularne robienie krótkich przerw zdrowotnych (**movement snacks**) na spacer lub ćwiczenia rozluźniające przykurczone mięśnie i pobudzające krążenie.

## Najważniejsze funkcje w wersji

- **Zdrowotne interwały ruchu:** Domyślnie skonfigurowana pod sesje pracy siedzącej przerywane aktywnymi przerwami.
- **Dwa tryby przerw:**
  - **Odliczanie do zera:** Precyzyjnie zdefiniowany czas na szybkie rozciąganie lub krótką przerwę (z możliwością dodawania czasu w locie przyciskami.
  - **Tryb stopera (0 min):** Liczy czas od zera w górę, idealny na dłuższą przerwę lub spacer.
